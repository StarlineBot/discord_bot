# 디스코드 턴제 전투 게임 — 설계 문서 (현재 상태)

> **현재 상태 기준(시간순 아님).** 앞에서부터 읽으면 지금 게임 그대로예요.
> 엔진·밸런스·UI 전부 `modules/battle.js`. 밸런스 시뮬: `node docs/battle-sim/game-balance-sim.js [반복수]`.

## 0. 개요

`/듀얼` — 프리셋 11종 중 하나로 랜덤 AI와 1:1 턴제. 게이지(턴값) 방식: `턴`값마다 행동, 빠를수록 자주. 매 턴 공격/방어/스킬을 버튼으로 선택. 타임아웃(t≥600)=무승부.

## 2. 2차 스탯 공식 (`derive`)

`step(s,per) = floor(s/10)×per`.

| 2차 | 공식 |
|---|---|
| 물공 | `round(힘×(1+step(힘,10)/100))` × 시그·무기 보정 |
| 마공 | `round(지능×(1+step(지능,10)/100))` |
| 최대HP | `round(500 + 체력×1.7 + 힘×0.5 + 지능×0.3 + 민첩×0.3 + 행운×0.5)` |
| 물방 | `min((step(힘,3)+step(체력,1))/100 + 무기물방 + 마도갑주, 0.80)` |
| 마방 | `min(min(30+step(지능,3),70)/100 + 무기마방, 0.85)` |
| 명중 | `min(35 + step(솜씨,5), 80)/100` (솜씨100은 90) |
| **물회(회피)** | `min(10 + step(민첩,1.8), 50)/100 + 무기회피보너스` |
| **마회** | `step(민첩,2)/100` |
| **리롤** | `min(step(행운,1.5), 50)/100` — 회피/명중 실패 시 2차 재굴림 (공/방 공용) |
| **천운** | `step(행운,1.5)/100` — 마법 완전회피 (리롤과 분리) |
| 크리 | `min(10 + step(솜씨,1) + step(행운,3.5) + 무기크리보너스, 70)/100` |
| 턴 | `max((10 - step(tempoVal,0.7)) × 무기tempoMul, 2)` — 작을수록 빠름 |
| 방패막기 | `검방 & 체력≥50 → (30 + floor((체력-50)/10)×3)/100` |
| 무기막기 | `힘≥50 → (30 + floor((힘-50)/10)×2)/100` |

- **tempoVal**: 기본=민첩 / 스태프·완드·마도검=지능 / 검오브·마도서=max(힘,지능).
- **크리배율**: base 물크1.5·마크1.2, 무기 `크리배율`이 덮어씀(활2.5·단검/마도서/검오브1.9).
- **물공 시그 보정**: 체력100+한손×1.3(기사) / 솜씨100+활×1.05(명사수) / **행운100+주사위×1.2(한탕)**.
- **실효 회피** = 물회 + (1−물회)×리롤.

- **원거리페널티**: 근접 공격자가 원거리 캐릭 때리면 그 공격자 턴 +N%.

## 7. 스킬 (캐릭당 액티브 + [패시브])

- 슬롯 최대 5(2줄 UI). `버프`=지속형(유지 중 재사용 불가), `시전`=캐스팅.
- **버프 원칙 개편**: 순수버프기는 공격 없음(턴 비용=리스크), 대신 효과 강함. (백스텝·2d20 등 일부만 딜)

**전사** — 방어파괴(3: 딜+받는뎀+15%+상대HP6%) · 돌진(5: 물방무시+2턴스턴, 자가-10%) · 차단(4: **확정명중** 시전취소+침묵/1턴스턴)
**광전사** — 재생의광기(5: 7%회복+3턴재생, **기절중 사용**) · 피의각성(버프: HP-10%→3턴 딜×1.35+명중보정) · **[불굴]** 죽을피해 1회 8%회복 생존+버스트완충
**기사** — 방패가격(3: 방어기반+상대HP10%) · 방패들기(버프: 방패막기 경감↑) · **[가시방패]** 12% 반사
**마법사** — 화염구(시전) · 메테오(긴시전·인캐불가) · 인스턴트캐스팅(버프: 다음시전 즉발) · **서리구**(짧은시전: 딜+상대둔화, 인캐즉발, AI는 빠른적한테만) · **[마나환류]** 마법딜 30% 확률 실드복구
**원드마법사** — **볼트마법조합**(순수버프: 4턴 볼트2발·다른종류 + **조합배율** 파라1.7/라아1.5/파아1.3) · 마력충전(5: 마나실드 재충전) · 볼트임팩트(시전: 마공×2.8)
**도적** — 암습(10: 3턴기절) · 처형(5: HP25%↓ 물공×5) · **백스텝**(4: **후측 강타 ×1.5**) · 입막음(4: 시전취소+침묵, 캐스터카운터) · **[연속타격]** 20% 추가타(크리제외)
**명사수** — 약점간파(4: 확정크리+방어무시) · 견제사격(4: 딜+명중-20%) · 연발사격(4: 3연사)
**한탕주의자** — **2d20**(버프: 3턴 **주사위 어드밴티지**, d20 2개 굴려 높은값) · 동전던지기(2: 50% 물공×8/50%×0.5) · 룰렛(3: 랜덤)
**세이지** — **오토스펠**(순수버프: 4턴 볼트프록 45% + **턴시간 15%↓**) · 연환주문(4: 혼합×2 + 상대HP6% 탱버스터) · **[원소스택]** 3타 폭발×1.3
**마검사** — 약점봉인(3: 순수CC) · 중력베기(4: 완전명중 딜×1.5+둔화) · **룬각인**(순수버프: 3턴 **공격력×1.8**)
**스펠브레이커** — 마나소각(3: 실드파괴+마공딜) · 시전파괴(4: 캐스터 침묵락/물딜러 자기기절) · **[마도갑주]** 상시 물방+12%

## 8. 핵심 시스템

**시전(cast)**: `s.cast`+`castDmg`+`castName`. upkeep 카운트다운 후 발사. 일반 마법판정(마방·천운·빗맞힘). **방해**: 피격5% 중단 / 기절·차단·입막음·시전파괴 즉시취소(castCarry로 다음-1턴). **인캐**: 3턴 버프, 다음 시전 즉발(메테오 제외).

**능동 방어 불가 조건** (`canDef = 기절0 && 시전0`): 기절 중 또는 **시전 중**엔 회피·천운·완전회피·방패막기·무기막기·주사위방어 전부 무효. 마나실드·반사·근성은 유지(수동).

**완전회피 3종**: ①sigDodge(행운100, 물리 15%) ②천운(행운10당 1.5%, 마법) ③회피(물회, 민첩). 실패 시 리롤(행운10당 1.5%)로 2차 재굴림.

**명중/빗맞음 구분**: 명중 실패=빗나감(0딜) / physSwing=딜변동 / 비껴(30%×0.70, 행운=비껴무효) 🌫️.

**마나실드**: 지능70+ 캐스터가 실드풀(HP22%)+마나경감(상시 받는뎀↓). 마력충전/마나환류로 재충전.

**AI**: 상대 시전 중 차단기 우선(차단·돌진·암습·약점봉인·시전파괴·입막음). 순수버프는 score(est배수)로 AI가 캐스팅 유도.

## 10. 밸런스 현황

- **스프레드 42.5~53.4 (폭 10.9)**, 11캐릭 정상권.
- 최대 극단: 스펠↔마법(안티캐스터 설계). 대체로 30~70.
- 도적 근접학살(전사·광전 60대): 속도×스턴 구조적 상성(RPS). 아웃라이어 아님.
- **설계 원칙**: ①속도가 밸런스 축(속도 버프는 지뢰). ②신규 딜은 넷-중립(상쇄). ③유틸/버프는 AI score 반영. ④순수버프=턴비용(리스크), 대신 강함. ⑤이미 강한 축은 스킬버프 효용 낮음(약점을 스킬로).

## 11. 참고·미구현

**커스텀 캐릭 (설계 완료)**: 공통 스킬 풀(`CUSTOM_DEFS`) 2개 선택 + 자유 스탯(예산~320·상한85). 검증 `custom-balance-sim.js`. 남은: 스킬/무기 선택 UI. **주사위 무기도 커스텀 사용 가능**(범용 밸런스).

**시뮬 코드**: `game-balance-sim.js`(11×11), `custom-balance-sim.js`. 소스오브트루스 직결.

**확장 여지**: 2줄 버튼 + 패시브 배열로 스킬 5개(액티브4+패시브1 등) 가능. 마법사·도적이 5스킬 예시.

**남은 작업/알려진 항목**:
- 한탕 42.5(회피/리롤 너프 직격), 원드 45.9·마검 45.4(순수버프 템포비용) — 완만한 바닥, 티어 범위.
- 백스텝(도적)·룰렛(한탕 luckBuff) 잔재 정리(playerCanUse dodgeUp 죽은 체크).
- 전적·승률 기록, PvP, 순차공개 간격 세분화.
