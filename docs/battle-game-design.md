# 디스코드 턴제 전투 게임 — 설계 문서 (현재 상태)

> **현재 상태 기준(시간순 아님).** 앞에서부터 읽으면 지금 게임 그대로예요.
> 엔진·밸런스·UI 전부 `modules/battle.js`. 밸런스 시뮬: `node docs/battle-sim/game-balance-sim.js [반복수]`.

## 0. 개요

`/듀얼` — 프리셋 11종 중 하나로 랜덤 AI와 1:1 턴제. 게이지(턴값) 방식: `턴`값마다 행동, 빠를수록 자주. 매 턴 공격/방어/스킬을 버튼으로 선택. 타임아웃(t≥600)=무승부.

## 2. 2차 스탯 공식 (`derive`)

`step(s,per) = floor(s/10)×per`.

| 2차 | 공식 |
|---|---|
| 물공 | `round(힘×(1+step(힘,10)/100))` × 시그·무기 보정 |
| 마공 | `round(지능×(1+step(지능,10)/100))` |
| 최대HP | `round(500 + 체력×1.7 + 힘×0.5 + 지능×0.3 + 민첩×0.3 + 행운×0.5)` |
| 물방 | `min((step(힘,3)+step(체력,1))/100 + 무기물방 + 마도갑주, 0.80)` |
| 마방 | `min(min(30+step(지능,3),70)/100 + 무기마방, 0.85)` |
| 명중 | `min(35 + step(솜씨,5), 80)/100` (솜씨100은 90) |
| 물회(회피) | `min(10 + step(민첩,1.8), 50)/100 + 무기회피보너스` |
| 마회 | `step(민첩,2)/100` |
| 리롤 | `min(step(행운,1.5), 50)/100` — 회피/명중 실패 시 2차 재굴림 (공/방 공용) |
| 천운 | `step(행운,1.5)/100` — 마법 완전회피 (리롤과 분리) |
| 크리 | `min(10 + step(솜씨,1) + step(행운,3.5) + 무기크리보너스, 70)/100` |
| 턴 | `max((10 - step(tempoVal,0.7)) × 무기tempoMul, 2)` — 작을수록 빠름 |
| 방패막기 | `검방 & 체력≥50 → (30 + floor((체력-50)/10)×3)/100` |
| 무기막기(확률) | `힘≥50 → (25 + floor((힘-50)/10)×1.5)/100` (무기 무관, 순수 힘). **무기의 달인**이면 힘10당 3% |
| 무기막기(경감) | 성공 시 피해 ×**0.7**(30%경감). **무기의 달인**이면 ×0.6(40%경감) |

- **tempoVal**: 기본=민첩 / 스태프·완드·마도검=지능 / 검오브·마도서=max(힘,지능).
- **크리배율**: 무기 `크리배율`(활2.5·단검/마도서/검오브1.9). **크리는 물리 전용** — 마법(볼트·매직미사일·혼합 마법몫)은 크리 없음(확정명중, 편차는 magicGraze 발당 1.0/0.8/0.4).
- **물공 시그 보정**: 체력100+한손×1.3(기사) / 솜씨100+활×1.05(사냥꾼) / 행운100+주사위×1.2(한탕).
- **실효 회피** = 물회 + (1−물회)×리롤.

## 4. 무기 (장비 1칸)

| 무기 | 계열/평타 | 사거리/손 | tempoMul | 특성 | 방어 |
|---|---|---|---|---|---|
| 검방 | 물/물 | 근접1 | 1.0 | 기본공1.0·받는뎀-10% | 방패막기 |
| 단검 | 물/물 | 근접1 | 1.0 | 기본공0.68·크리+15%·크리배율1.9·회피+10% | 패링\* |
| 쌍검 | 물/물 | 근접2 | 1.0 | 기본공0.6·다단2 | 패링\* |
| 양검/양둔/양도끼 | 물/물 | 근접2 | 1.25 | 기본공1.25/1.2/1.4 · (양둔 스턴20%·양도끼 관통0.3) | 무기막기 |
| 활 | 물/물 | 원거2 | 1.0 | 기본공1.05·크리배율2.5·회피+5%·원거리페널티0.4 | 회피 |
| 스태프 | 마/마 | 원거2 | 1.65 | 지능템포·평타0.55·castMod-2·원거리페널티0.35 | 마나실드 |
| 완드 | 마/마 | 원거1 | 0.75 | 지능템포·평타0.9·마뎀0.66·원거리페널티0.15 | 마나실드 |
| 마도서 | 마/**혼합** | 근접2 | **0.95** | 힘지능템포·**물타1.1·물리관통0.3**(마법몫은 볼트로)·크리배율1.9 | 무기막기 |
| 검오브 | 마/**혼합** | 근접1 | 1.08 | 힘지능템포·**물타0.87·마타0.87**·크리배율1.9 | 무기막기 |
| 마도검 | 마/마 | 근접1 | 0.95 | 지능템포·마방+15% | 무기막기 |
| 주사위 | 물/물 | 근접2 | 1.0 | 기본공1.0·**d20**(한탕 전용) | 주사위굴림 |

- **방어기제**(피격 시): 방패막기(검방·체력≥50·×0.20·마법도) / 무기막기(힘≥50·×0.7, 무기의 달인 ×0.6) / 회피(물회) / 마나실드(흡수) / 주사위(아래).
- **\*패링은 라벨만, 미구현** — 단검·쌍검의 실제 방어는 회피(민첩)뿐(힘<50이면 무기막기도 없음).
- **주사위(d20)**: 공격 1=대실패(1딜)/20=대성공(×3)/2~19=굴림/13. 방어 1=받는뎀×2/20=1/2~19=완만. 무기막기 없음.
- **원거리페널티**: 근접 공격자가 원거리 캐릭 때리면 그 공격자 턴 +N%.
- **혼합 스윙**(마도서·검오브): 물리(vs 물방) + 마법(vs 마방)을 **각자 방어로 따로** 계산 → 물딜·마딜 상대 모두에게 통함(관통형). 물리 판정이라 능동방어 발동.

## 7. 스킬 (캐릭당 액티브 + [패시브], 최대 5)

- `버프`=지속형(유지 중 재사용 불가). `시전`=캐스팅. 순수버프기는 공격 없음(턴 비용=리스크), 대신 효과 강함.
- **선언형 스킬 스키마**: 스킬 정의가 `tag`(공격/제어/버프/디버프/회복/관통/시전)·`coef`(또는 `mult`+`dmg{selfHp/foeHp/force…}`)·`cd`/`buff` 필드를 직접 보유. `composeDamage`(딜)·`skillLine`(설명)이 이 필드에서 자동 생성 → **캐릭 선택 UI 스킬블록·버튼 라벨·쿨 전부 하드코딩 없이 자동**(스킬 추가/삭제 = 정의 한 곳만 수정). 구 `SKILL_DESC`/`SKILL_CD` 테이블 제거.

**검투사** — 방어파괴(쿨3: 딜+받는뎀+상대HP9%) · 돌진(쿨6: 물방무시+2턴스턴, 자가-10%) · 방해(쿨5: 확정명중 시전차단/1턴스턴+딜×1.0) · **발차기**(쿨4: 1턴스턴, 딜0 순수CC) · **[무기의 달인]** 무기막기 확률·경감↑ + 무기(물리)딜 ×1.1. CC 3개로 압도
**광전사**(4액티브·1패시브) — 피의갈증(쿨1: 타격+회복, 광란이 회복계수 증폭) · 피의격노(버프: HP-15%→3턴 공격력×1.35) · 격돌(쿨2: 1턴스턴+HP-5%) · **해방**(쿨13→15: 체력 15% 즉시회복 + **행동불능 즉시해제**, `stunnable`=기절 중 사용 가능 — 근접 CC 카운터의 오프너 탈출용, 긴 쿨이라 판당 사실상 1회) · **[피의굶주림]**(격노+광란 통합 패시브) 체력↓→공격력 급증(빈사~+90%, **회복하면 감소**=자기조절)+받는제어↓+턴가속+회복계수↑(2차곡선). **불굴 삭제=안전망 없는 하이리스크**(피 태워 저체력 스파이크 ↔ 처형/버스트에 취약). 해방으로 근접 CC 상성(암살자 17→42%) 접전화. *격노·광란 플래그는 정의 보존(커스텀용), 광전사엔 피의굶주림만 할당*
**기사** — 방패밀쳐내기(쿨3: 딜+상대HP10%, 순수딜) · 방패들기(버프: 방패막기45%→90%) · **방패가격**(쿨4: 시전 중이면 즉시 차단+공격력 소폭↑ / 아니면 1턴 스턴 — 유일한 제어기) · **[완벽방어!]** 연속 방패막기 2회 성공 시 그 순간 **막기 전 원피해의 0.7을 공격자에게 즉시 반사**(실드 무시). 방패들기(90%)와 강시너지 — 많이 때리는 물리 상대를 응징(가시방패 반사12% 대체)
**마법사** (5액티브·무패시브) — 화염구(시전~4턴, 마공×4.8) · **메테오**(시전~7턴, 인캐불가, **끊기 불가=시작하면 기절·침묵·차단 무시하고 완성**, 화염구와 raw 딜/턴 1:1) · 인스턴트캐스팅(버프: 다음시전 즉발) · 서리구(시전~3턴: 약딜+둔화, 인캐즉발) · **충격파**(쿨5·즉발: 소량딜 + **상대 현재 턴 진행 초기화** + 1턴 둔화, **기절 중에도 사용=위기탈출**) · **[시그=지능100]** 마나실드 최대 40% + 매턴 4% 자가재생(시전 중에도)
**볼트마법사**(시전형 볼트) — 평타=**매직미사일**(단발) · **파이어볼트**(2시전·발당0.6) · **라이트닝볼트**(1시전·0.35) · **콜드볼트**(즉발·0.2+1턴둔화·쿨1) — 화염구식 시전마법, 발수 1~5(이해면 5고정), 발당 마방·graze 개별 · **볼트마법조합**(버프: 볼트류 **시전+1** + **착탄마다 다음 원소 자동 후속**=파이어→라이트닝→콜드→파이어) · **[볼트마법의 이해]** 원소당 확정 5발
**암살자** — **암습**(쿨10: **확정 3턴 스턴, 딜0** 순수CC) · 처형(HP25%↓ 물공×5) · 백스텝(후측 강타×1.5) · 입막음(쿨5: 시전취소+2턴침묵〈마법 전용 봉인〉+확정딜×1.0) · **[연속타격]** 20% 추가타(크리제외)

**볼트 시스템(공통·단일 소스 `BOLT_CAST`/`boltShot`)**: 볼트 발당 = `마공 × 계수 × (1-마방) × magicGraze` — **크리 없음**(발당 편차 magicGraze 1.0/0.8/0.4). 계수 **파0.6/라0.35/콜0.2**. 발수 1~5(볼트마법의 이해면 5고정), **발당 마방·graze 개별 적용**(한방 아님). 발동 방식만 다름 — **볼트마법사=시전형**(파이어2/라이트닝1시전·콜드 즉발) / **세이지=오토스펠 랜덤 즉발**(원소의 이해 ×3.0). 볼트마법조합: 착탄마다 다음 원소 자동 후속(활성 중 볼트류 시전+1).

## 8. 핵심 시스템

**AI (예측 기반 3종)** — 매 턴: ①상대 시전 중이면 차단기 우선 ②방어 판단(아래) ③스킬(스코어 최고, 평타 기준선 `ctx.est` 초과 시) ④평타.
- **스킬 스코어 = "이번 턴 HP 가치"로 통일**(3계통, `tag`로 분류) → 평타 HP가치와 직접 비교:
  - **딜점수** `dmgVal` = 기대딜/커밋턴 + 붙은 CC(제어점수) − 시전리스크(무방비턴×foeTurn×0.2). **처치 가능하면 총딜로 승격**(막판 버스트). 시전마법은 커밋턴으로 나눠 라이트닝/화염구가 제대로 뽑힘.
  - **제어점수** `ctrlVal` = 상대 봉쇄 HP = `foeTurn × 봉쇄턴 × 효율`(스턴0.9>침묵0.6>둔화0.4>약화0.35…). **상대가 안 걸렸을 때만**(중복 방지). 시전차단(vs 캐스터)은 최우선.
  - **방어점수** `buffVal` = 버프 총 이득 × 생존여유(저HP면↓, 죽을 턴에 버프 방지). 미보유 시만(ready 게이트).
- **기준선 `estAtk`**: 평타 기대딜. 캐스터는 무기 평타계수·마뎀너프 반영(스태프0.55·완드0.66 — 과대평가 방지).
- **방어 결정** = 예상피격(estAtk×1.3−실드) × 리스크계수 ≥ 내HP → 방어. **공격적** 계수0.6(딱 죽을때만) / **판단형** 0.85 / **방어적** 1.15(선제적).
- **버프 게이트**: 공격적=항상 / 판단형=여유 있을때 / 방어적=아주 안전할때만.
- **시전 리스크**(`x.safe`): 시전 N턴 무방비 → 견딜 수 있을때만 시전. 물리 즉발은 리스크 0.

**시전(cast)**: upkeep 카운트다운 후 발사. 일반 마법판정(마방·천운·빗맞힘). **방해**: 피격5% 중단 / 기절·차단·입막음·시전파괴 즉시취소(castCarry로 다음-1턴). **단 메테오는 예외 — 시작 후 끊기 불가**(기절 중에도 진행). **인캐**: 다음 시전 즉발(메테오 제외).

**제어 스킬 쿨/지속**: 돌진(스턴2·쿨6) · 차단(침묵1/스턴1·쿨5) · 암습(스턴3·쿨10) · 입막음(침묵2·쿨5) · 약점봉인(적응형·쿨5) · 시전파괴(침묵2·쿨5) · 방패가격(기사: 시전차단 or 1턴스턴·쿨4) · 서리구(둔화3) · 충격파(턴 초기화+둔화1·쿨5). → 긴 시전보다 쿨이 길어야 매 시전마다 안 끊김(마법사 시전 병목 해소).

**침묵 = 마법 스킬 전용**(`MAGIC_SKILLS` Set): 침묵 상태에선 **마법 스킬만 사용 불가**, 물리 스킬은 정상 사용. "주문을 못 왼다"는 원래 의미로 정합 — 물리 전사는 침묵 면역이 아니라 "막을 마법이 없는 것". 침묵 소스 4종(입막음·방해·시전파괴·룰렛)이 모두 같은 `f.silence` 상태를 쓰므로 게이트 한 곳으로 일괄 적용.
- **마법 분류**(막힘): 마법사·볼트·세이지 전 스킬 + 스블(룬각인·역장폭발·약점봉인) + 스브(마나소각·시전파괴). **버프도 마법**(주문 영창). **물리**(통과): 물리캐 전 스킬 + 스블 역장베기(타격 주체) + 스브(무기파괴·파훼) + 물리 버프(피의격노·방패들기) + 물리 덫(사냥꾼덫).
- **AI 침묵 점수 정합**: 침묵 CC 가치를 **상대 마법 비율**(`magicShare` = 상대 마법스킬수/전체, 캐스터 1.0·스블 0.75·스브 0.5·물리 0)로 스케일 → 물리 상대에겐 침묵 우선순위 소멸. 시전 중인 상대 차단은 여전히 최우선.
- **입막음 확정딜 유지**: 입막음(배율 ×1.0)은 **확정 명중**이라 상대 회피(물회)를 건너뜀 → 딜 추정치를 `x.est ÷ (1−상대물회)`로 잡아, 침묵값이 0인 물리 상대에게도 **딜 필러**(+18~32%)로 정상 선택. AI 미스플레이 방지.

**능동 방어 불가**(`canDef = 기절0 && 시전0`): 기절/시전 중엔 회피·천운·완전회피·막기·주사위방어 무효. 마나실드·반사·근성은 유지.

**방패막기(검방)**: 물리뿐 아니라 **시전 마법(화염구/메테오/서리구)도 20% 경감**(방패들기 중 10%). 확률 발동 — 마법 평타는 `attack()`, 시전 마법은 `spellDmg()` 양쪽 모두 적용. **약점간파(확정명중타)도 `attack()` 경로라 방패막기·무기막기로 막힘** — 회피만 무시.

**확정타의 방어 규칙**(`guaranteed` 플래그): 방해·입막음·약점간파처럼 "확정명중"은 **회피(dodge)만 무시**하고 **막기·방어구(방패막기·무기막기·물방·근성·마나실드)는 정상 적용**. 엔진이 방어를 "회피류(확정타에 뚫림) vs 막기·방어구류(항상 적용)" 2종으로 분류. 약점간파는 여기에 `forceCrit`(확정크리) 추가. *(전면 방어행동 분류 매트릭스는 백로그)*

**완벽방어!(기사 패시브)**: `perfectGuard`. **연속 방패막기 N=2회 성공** 시 그 순간 막기 전 원피해(`fin/방패계수`)의 0.7을 공격자에게 즉시 반사(실드 무시 직접딜). 스트릭은 방패막기 외 결과(피격·회피)에 리셋. **자기균형** — 많이 때리는 물리 상대일수록 자주 걸려 응징, 시전/도박형엔 거의 무발동. 딜 숫자를 안 키워 "탱커에 딜 더하면 폭발" 문제 우회.

**현자의 균형(세이지 패시브)**: 힘·지능 **둘 중 낮은 값** 기준 상시 피해감소(`min(step(min(힘,지능),2.5),16)%`). `gutsMul`/`guts`에 곱해 물리·마법 공통 적용(실드 흡수 전). 스탯이 게이트라 순수 빌드(마법사 힘10/암살자 지능15)엔 0에 수렴 → 하이브리드 전용, 커스텀 상정 안전.

**패시브 토대**: 패시브를 일급 취급 — `PASSIVE_FLAGS`(표시명→플래그 레지스트리) + fighter `passiveLock` 타이머 + `psv(f,flag)=플래그보유 && !잠김` 헬퍼. 런타임 패시브(완벽방어·행운의여신·연속타격·볼트마법의이해·원소의이해·격노·광란×2·무기의달인) + 현자균형이 이 게이트를 거침. `passiveLock=0`이면 기존과 100% 동일. (마도갑주만 derive 물방 baked라 lock 미대응 — 등록만. 불굴은 미배치=창고 대기)

**디스펠(세이지)**: 상대 `passiveLock=3`(패시브 3턴 봉인) + `clearBuffs`(버프 필드 일괄 제거: rage·powBuff·blockUp·dodgeUp·magReflect·luckBuff·chainBolt·autoSpell·healRegen·instCast·accBuff — 실드·시전은 자원/채널이라 제외). 딜 없음, 쿨=봉인+2=5. AI는 상대가 버프 보유 or 강패시브(불굴·완벽방어·행운의여신) 있을 때만 시전(딜턴 낭비 방지).

**마법 5속성 분류(`MAGIC_ELEM`)**: 화염🔥/전격⚡/냉기❄️(=**원소**, 마방 적용) · 역장🟣(마방무시 관통) · 무⚪(비원소). `isElemental`(원소3종)/`isPierce`(역장) 헬퍼. **원소의 이해**는 원소 3종만 강화(역장·무 제외). 볼트=원소, 화염구=화염, 서리구=냉기, 메테오·충격파·매직미사일=무, 역장베기/폭발/마나소각=역장.

**역장피해(force)**: `마공×계수` flat, **물방·마방 무시**(D&D force — 저항 거의 없음). 스펠블레이드 역장베기·역장폭발 + **스펠브레이커 마나소각**(마방 높은 캐스터 관통용). 마나실드엔 흡수됨(마나소각은 실드 선파괴 후 HP직격). 나레이션 **🟣 마커**.

**무기파괴 디버프**: 상대 딜 ×1/3(물/마 공통) + 무기막기 불가. 스펠브레이커 킷의 핵심(→파훼 콤보).

**출혈(🩸)/덫(🪤)**: 사냥꾼덫 = 예약형(f.trap 카운트다운, 2턴 뒤 발동) → 게이지 밀림 + 1턴 둔화 + **출혈 3턴**(발당 물공×0.3, 방어·실드 무시 DoT). DEBUFFS 레지스트리(범용 디버프 9종)에 새 디버프 추가 시 룰렛 자동 포함.

**관통 통합**: `defMul(방어, 관통) = 1 − 방어×(1−관통)`. 관통 0=방어 전부 / 1=방어무시(역장) / 0.25=25%무시. sigPen(힘100 물방0.30)·tMPen(심연의 마방0.25)·무기관통을 물관통/마관통 단일값으로.

**마나실드 일관성**: **모든 물리·마법 딜은 마나실드에 흡수됨**(방어무시=물방/마방 무시이지 실드무시 아님). HP%딜도 실드 흡수(방패밀쳐내기 모델). 예외는 **마나소각**(실드 선파괴)뿐. 동전·방어파괴·처형·견제·시전마법 모두 absorb 경유.

**완전회피 3종**: sigDodge(행운100 물리15%) / 천운(행운10당1.5% 마법) / 회피(물회). 실패 시 리롤(행운10당1.5%) 2차 재굴림.

**마나실드**: 지능70+ 캐스터가 실드풀(HP22%)+마나경감(상시 받는뎀↓). 볼트마법사는 마력충전으로 재충전. **마법사(지능100 시그)는 실드풀 40% + 매턴 4% 자가재생**(시전 중에도 — 시전 중 사망 약점 해소). 스펠브레이커 마나소각이 이 실드의 카운터.

## 12. HP/SP/MP 자원 시스템 (설계 확정·미구현)

> 마나실드를 자원 시스템으로 개편. **스킬이 SP/MP를 소모** → "쿨만 되면 쓴다"가 아니라 **언제 자원을 태울지**가 핵심 결정이 됨. HP처럼 캐릭터 밑에 3바(HP/SP/MP) 표시(Discord 코드블록, 색 대신 라벨 구분).

### 12.1 3자원 — 생성 스탯 기반 풀
| 자원 | 최대치(공식·자리표시자) | 생성 스탯 |
|---|---|---|
| **HP** | `500 + 체력×1.7 + 민첩×0.6 + 행운×0.6` | 체력/민첩/행운 (힘·지능 제거) |
| **SP** | `100 + 힘×1.2 + 솜씨×0.8` | 힘/솜씨 (물리 자원) |
| **MP** | `100 + 지능×1.2 + 행운×0.8` | 지능/행운 (마법 자원) |

- **off-자원 자연 사장**: 물리캐는 MP 작고 안 씀, 마법캐는 SP 작고 안 씀 → **필요한 자원이 큰 스탯에서 크게** 나옴(광전사 힘100=SP부자 / 마법사 지능100=MP부자). 자기조절.
- **행운은 HP·MP 이중** 기여(한탕·암살자 MP 여유).

### 12.2 회복 — 생성 스탯 비례(높을수록↑, 이중 보상)
| 자원 | 턴당 회복 | |
|---|---|---|
| HP | `1% + step(체력,0.5)%` (소량) | 체력100 ≈ 6%/턴 |
| SP | `10% + min((힘+솜씨)/16, 10)%` = **10~20%** | 힘+솜씨↑ = 회복↑ |
| MP | `10% + min((지능+행운)/16, 10)%` = **10~20%** | 지능+행운↑ = 회복↑ |

→ 스페셜리스트 = **큰 풀(버퍼) + 빠른 회복** 이중 보상 → 자기 스킬을 확실히 더 자주.

### 12.3 코스트 — **고정값**(%가 아님)
- **왜 고정값?** %코스트+%회복이면 풀 크기가 무의미(비율이 상쇄). **고정 코스트**여야 큰 풀 = 더 많은 연발 버퍼 + 15% 회복의 절대량이 커서 재충전이 빠름 → 스페셜리스트 우위 성립.
- **코스트 = 스킬 스코어(§8 정적가치) × k** → 강한 스킬 비쌈·약한 스킬 쌈이 **자동 산출**(하드코딩 없음). 제어기는 `× 1.3` 추가(봉쇄가 딜보다 비싸게).
  - 코스트용 정적가치는 **처치승격 제외**(메테오 등)·평상시 per-turn 기준. 충격파(게이지리셋)·덫·룰렛 등 특수기는 별도.
  - 스코어 스펙트럼(기준상대=검투사): 싼 편 백스텝39·발차기62 / 중간 90~150 / 비싼 편 돌진282·방패밀쳐내기266·암습226·처형217.
- **1콤보 보장**: `풀 ≥ 콤보 스킬 코스트 합`(예 암습+백스텝)이 되게 k·기본풀 조정 → "SP 모아 1콤보 vs 매턴 제어기"가 실제 자원 계산이 됨.
- **평타 무료**(마법무기 평타 포함).
- **시전**: 총코스트를 시전턴에 분할(화염구 30% → 4시전 시 7.5%/턴) + **시전 중 회복 정지/소량**. 중간에 끊기면 덜 소모(자원 이득).

### 12.4 마나실드 통합
- 마나실드 = 발동률 그대로 + **블록당 MP 소모**. MP가 (마나소각 등 타인에 의해) **0이 되면 취약**(실드 불가). 스펠브레이커 마나소각이 "실드파괴"→"MP고갈"로 자연 통합.

### 12.5 스킬 → 자원 배정
- **물리캐 → SP**(검투사·광전사·기사·암살자·사냥꾼·한탕 전 스킬)
- **마법캐 → MP**(마법사·볼트마법사·스펠브레이커 전 스킬 + 마나실드)
- **세이지 → MP**(물리 스윙에 마법을 얹은 형태 → 자원은 MP)
- **스펠블레이드 → 이중**: 역장베기·역장폭발 = MP / 약점봉인·룬각인 = SP (SP·MP 둘 다 관리하는 하이브리드)

### 12.6 AI 연동
- **가용성 게이트**: 스킬 ready에 `SP/MP ≥ 코스트` 추가(자원 부족 시 후보 제외 → "다음 공격 가능한지"는 게이트로 자동 처리).
- **버스트 예약 휴리스틱**: 저HP 상대 있으면 처치기 코스트만큼 자원 남기기(마지막 SP를 제어기에 낭비 방지).
- 코스트가 스코어 비례라 "가치/코스트 ≈ 일정" → AI는 효율이 아니라 **예산 배분**(이번 턴 뭘 살까)으로 결정. 턴당 산출 = 회복량 상한.
