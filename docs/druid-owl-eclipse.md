# 드루이드 마나부엉이 개편 — 일월식 (기획 확정·미구현)

> 상태: 기획 확정, 구현 대기. 수치는 1차 초안이며 구현하면서 `node docs/battle-sim/game-balance-sim.js`로 검증·조정한다.
> 기준 코드: `main` `3828f19` (`modules/battle.js` 드루이드 섹션 — `DRUID_FORMS`, `DRUID_SKILLS.마나부엉이`, `owlCast`, `owlDot`, `starDotTick`, `druidShift`, `druidPickForm`)

## 1. 배경 — 왜 바꾸나

현재 마나부엉이:

| 슬롯 | 스킬 | 내용 |
|---|---|---|
| 1 | 달빛섬광 | 시전 1턴, 마공×1.7 |
| 2 | 별빛섬광 | 시전 2턴, 마공×1.5 ×2타 |
| 3 | 별빛쇄도 | 5턴 지속피해 상대 최대체력 5%/턴, 쿨5 |
| 4 | 별똥별 | 5턴 지속피해 상대 최대체력 7%/턴, 쿨7 |
| 5 | (형상변환) | |

형상 특성: 최대체력×0.6, 마나실드(지능×14 + 체력×7 = 1295, 재충전 없음 — 해제 시 보관·재변신 시 복원), 평타=마법.

문제점:
- **고유 자원·연계가 없다.** 곰(분노·광포한 재생력), 표범(콤보 포인트·은신→암습), 치타(기력 비축·재생)와 달리 어떤 순서로 써도 결과가 같다.
- **"마나" 부엉이인데 마나실드를 굴리는 재미가 없다.** 한 번 깎이면 끝.
- **달/별 이름에 의미가 없다.** 별빛쇄도·별똥별은 둘 다 지속피해라 역할까지 겹친다.
- 스킬줄 5칸 중 4칸만 사용(형상변환은 행동줄로 빠짐).

### 시뮬레이션 기준값 (상대 16종 × 150~200판, 개편 전)

| 조건 | 드루이드 승률 | 비고 |
|---|---|---|
| 현행 AI | **55.8%** | 행동 비중: 곰 42.9% · 표범 40.7% · **부엉이 11.8%** · 치타 4.5% |
| 부엉이 주력 강제 | 40.4% | 기사 89%·스펠브레이커 93% / 광전사 1%·마법사 23%·암흑기사 23% |
| 표범 주력 강제 | 45.9% | 기사 1% |

→ 부엉이는 지금 "느린 물리 탱커 전용 카운터"(AI도 `shieldWeak`일 때만 선택). 드루이드 전체는 이미 평균 이상이므로 **총 딜 예산은 유지하고 플레이 구조·생존 방식을 바꾸는** 개편이다.

## 2. 컨셉

| 계열 | 성격 | 이미지 |
|---|---|---|
| 🌙 달 | 지속·수호·안정 | 고요한 달빛이 마나를 채운다 → 마나실드 재충전 |
| ⭐ 별 | 폭발·다단·마무리 | 쏟아지는 별 → 순간 화력 |

"달로 버티며 준비 → 별로 터뜨림"의 순환으로 곰(버팀)·표범(폭딜) 사이 부엉이 자리를 만든다.

## 3. 일월식 규칙 (교차 충전)

```
🌙 달 스킬 사용 → ⭐별 충전 +1 → 2 모이면 ☀️일식(별 스킬 강화) 진입
⭐ 별 스킬 사용 → 🌙달 충전 +1 → 2 모이면 🌑월식(달 스킬 강화) 진입
```

| 항목 | 규칙 | 이유 |
|---|---|---|
| 지속 방식 | **강화 2회분**(턴 수 아님) | 시전 2턴 스킬·기절 때문에 턴 기반 버프가 허무하게 끝나는 것 방지 |
| 강화된 스킬의 충전 | **반대편 충전함** | 순서대로 번갈아 쓰면 강화가 이어지고, 순서를 틀리거나 기절로 끊기면 빠진다 → 실력 차 |
| 동시 보유 | 불가(천체 정렬 중만 예외) | 새 식 진입 시 이전 식의 남은 강화는 소멸 |
| 부엉이 해제 시 | **충전·식 모두 초기화** | 미리 쌓아두고 형상 왕복하는 꼼수 차단. 마나실드만 기존처럼 보관 |
| 천체 정렬 | 충전 대상 아님 | |

리듬(＊=강화 사용):

```
달 달 → ☀️ → 별＊ 별＊ → 🌑 → 달＊ 달＊ → ☀️ → 별＊ 별＊ …
```

## 4. 스킬 (수치 1차 초안)

기준: 마공 102(지능 65), 실드 최대치 1295.

| 슬롯 | 계열 | 스킬 | 기본 | 강화 | 쿨 |
|---|---|---|---|---|---|
| 1 | 🌙 | **달빛섬광** | 시전 1턴, 마공×1.6 (1.7→하향) | 🌑월식: **즉발** | 없음 |
| 2 | 🌙 | **월광** (별빛쇄도 대체) | 5턴 지속피해, 상대 최대체력 4%/턴 (5%→하향) | 🌑월식: 부여 즉시 1틱 + 지속 7턴 | 5 (효과가 끝나야 쿨 진행 — 기존 ccLock 규칙) |
| 3 | ⭐ | **별빛섬광** | 시전 2턴, 마공×1.4 ×2타 | ☀️일식: 시전 1턴 + **3타** | 없음 |
| 4 | ⭐ | **별똥별** (지속피해 → 착탄형) | 시전 2턴, 마공×2.6 단발 | ☀️일식: 착탄 시 상대에게 걸린 **월광의 남은 피해 전부 즉시 폭발**(월광 종료) | 4 |
| 5 | ✨ | **천체 정렬** (신규) | 즉시 사용(1턴 소모). 3턴간 월식+일식 동시(모든 스킬 강화) + 마나실드 최대치 30% 충전 | — | 12 (시작 쿨 3) |

### 공통 — 월식 마나실드 재충전
- 🌑월식 중 달 스킬(달빛섬광·월광)을 쓸 때마다 마나실드를 **최대치의 10%(≈130)** 충전.
- 최대치(`owlCap`) 초과 불가. 실드가 0으로 깨진 상태에서도 충전된다(다시 실드가 생김).
- 천체 정렬 중에도 적용.

### 설계 의도
- **달빛섬광·월광 소폭 하향**: 월식 실드 재충전으로 생존력이 새로 생기므로 그만큼 딜 예산을 덜어냄(드루이드가 이미 55.8%).
- **별똥별 폭발 ↔ 월광 쿨**: 월광은 "효과가 끝나야 쿨이 돈다". 별똥별로 일찍 터뜨리면 피해를 앞당겨 받는 동시에 월광 쿨도 일찍 돈다 → 총 딜을 크게 늘리지 않고 "달을 깔고 별로 터뜨린다"는 연계 보상.
- **천체 정렬**: 마무리 구간 겸 위기 탈출기. 실드 30% + 즉발 달빛섬광으로 버티며 3타 별빛섬광·별똥별 폭발로 몰아친다.

## 5. UI·내레이션

- 상태줄: `🦉마나부엉이 · 🌙●○ ⭐●● · 🌑월식 2회 · 🛡️820/1295`
  - `🌙●○` = 일식까지 남은 달 충전 / `⭐●●` = 월식까지 남은 별 충전
- 스킬 버튼: 강화 중인 계열 버튼을 초록(Success) + 🌑/☀️ 접두로 표시. 기존 `comboLvl` 버튼 강조 로직 재사용 가능.
- 내레이션 예시
  - 🌑 **월식!** 차오른 달빛이 마나를 채운다. (실드 +130)
  - ☀️ **일식!** 별들이 궤도를 맞춘다.
  - ✨ **천체 정렬!** 해와 달과 별이 한 줄로 섰다.
  - ☄️ 별똥별이 떨어지며 월광을 터뜨렸다! (남은 월광 피해 N 즉시)

## 6. AI

- 스킬 점수(`score`)
  - 이번 사용으로 반대편 식이 열리면 가산점.
  - 식 진행 중이면 강화 계열 우선.
  - 별똥별 폭발은 월광 남은 틱이 3 이상일 때만 가치 있게.
  - 천체 정렬: 상대 체력이 낮아 마무리각이거나, 실드가 비고 체력이 위험할 때.
- 형상 선택(`druidPickForm`): 실드 재충전으로 버팀이 생기므로 부엉이 선택 조건을 완화(예: `OWL_HOLD` 10→8). 정확한 값은 시뮬로 결정.

## 8. 검증 목표 (시뮬)

| 지표 | 개편 전 | 목표 |
|---|---|---|
| 드루이드 전체 승률 | 55.8% | **55% 이하** (가능하면 52~54%) |
| 부엉이 행동 비중 | 11.8% | **20~30%** |
| 부엉이 주력 강제 승률 | 40.4% | **45~48%** (표범 강제 45.9%와 비슷하게) |

부엉이 강화로 전체가 55%를 넘으면 부엉이를 다시 깎기보다 곰(행동 비중 42.9%) 조정을 우선 검토한다.
