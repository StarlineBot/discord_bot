# 디스코드 턴제 전투 게임 — 설계 문서

> 새 세션에서도 작업 이어갈 수 있게 현재까지의 설계를 정리한 문서.
> 20년 전 콘솔 RPG(1~4 입력 턴제 전투)를 디스코드 버튼 UX로 부활시키는 프로젝트.
> 밸런싱은 콘솔 시뮬레이터(`~/.claude/jobs/*/tmp/battleV*.js`, **임시폴더라 휘발됨 → 아래 6-A 참고**)로 진행.

## 0. 프로젝트 개요
- **무엇**: 디스코드 봇 안 캐릭터 턴제 전투 게임
- **조작**: 버튼(공격/방어/스킬/도망) — 콘솔 "1~4 입력"의 현대판
- **표시**: 임베드 + `interaction.update()` 갱신 (HP바/데미지 연출), customId 상태 인코딩(무상태, 성수깡 버튼 패턴)
- **모드**: PvE(랜덤 AI) + PvP(길드원, 나중에)
- **리텐션(나중)**: 전적 기록 + 승률 랭킹 + 타이틀 수집. **기록/DB는 나중, 지금은 전투 시스템 설계 먼저**
- **커스텀 캐릭(나중)**: 총 포인트 배분 + 스킬 선택. 프리셋은 "추천 빌드"로 병행

## 1. 진행 상황
- ✅ **스탯 시스템** 확정 (6스탯 + 파생 공식)
- ✅ **전투 판정** 확정 (물리/마법 이원화, 방어기제, 크리, 근성)
- ✅ **7캐릭 프리셋** + 기본 밸런스 완료
- ✅ **특수스킬 1번째** 7종 확정 (전원 살아남, 밸런스 37~57%)
- ✅ **특수스킬 2번째** 7종 확정 (전원)
- ✅ **AI 태그 기반 재설계** — 스킬에 태그(딜/제어/조건부) + 점수 선택기. 하드코딩 우선순위 버그 제거
- ✅ **시그니처 패시브** — 1차 스탯 100 도달 시 스탯 고유효과. 밸런스 43~56%로 압축
- ✅ **타이틀 시스템** — 캐릭 선택 시 랜덤 1개(가중), 매판 변수. 23종(일반16+레어2+꽝5), 캐릭 밸런스 안 깨짐
- ✅ **세이지(8번째)** — 혼합 타격(물리+마법 절반씩 각자 방어) 하이브리드. 오토스펠(볼트 3종)+연환주문
- ✅ **마검사(9번째)** — 융합 타격(물+마 합쳐 한 방, 방어자 max방어로만 경감) CC 특화. 적응형 CC(약점봉인)+중력베기
- ✅ **광전사 보정** — 피의갈망→재생의광기(즉시 25%+3턴 재생). 마검사 힘-스턴 2→1턴으로 완화. 9캐릭 41~56%
- 🔶 **디스코드 구현** — `/듀얼` 1차: 캐릭 선택 → 랜덤 상대·AI → 자동 전투 + 극적 내레이션(직업 '타이틀' @멘션, 스킬·기절·크리·HP바). `modules/battle.js`(엔진 이식)·`commands/duel.js`
  - **게임 밸런스판(HP×1.3, 전투 길이 튜닝)** — 시뮬 기본(HP×1)은 중앙 4턴으로 짧아, 게임은 아래 델타로 중앙 6턴 + 밸런스 43~57 유지:
    - **HP ×1.3** (전투 길이↑) · 스킬 시작쿨 0(원래 시뮬처럼) · 게이지 랜덤오프셋(선공 공정)
    - **마법 빗맞힘 구간** 신설: 마법 평타 30% 풀딜 / 40% 80% / 30% 40% (평균 74%). "마법=확정명중"이 긴 전투서 자동명중 우위 → 빗맞힘으로 완화 (마법사 전용 분기라 하이브리드 불영향)
    - **물리 명중 기본 20→28** (물리캐 신뢰도↑, 자동명중 격차 양방향 축소)
    - 메테오 시전 3→4턴, 동전던지기 all-or-nothing 유지·쿨 3→2, 세이지 혼합계수 0.85→0.78, 명사수 약점간파 ×1.2, 마나실드 0.3→0.22
  - `modules/battle.js`의 `TUNE`(hpScale·skillStart)로 노브화 — 재현/조정 가능
  - ✅ **인터랙티브 턴**: 매 턴 버튼(공격/방어/스킬1/스킬2)으로 유저가 행동 선택, 상대 AI 자동. 스텝형 엔진(upkeep/advance/playerResolve), 세션은 메시지별 in-memory(30분 TTL). HP바·상태태그·자연스러운 RPG 로그(조사 자동교정)
- ⬜ **전적/승률 기록** · **커스텀 캐릭** — 다음

## 2. 스탯 시스템 (6스탯, 각 0~100)
| 스탯 | 담당 |
|---|---|
| **힘** | 물리공격 · 물리방어 · 무기막기 |
| **지능** | 마법공격 · 마법방어 · 마나실드 |
| **체력** | HP(주력) · 근성 · 방패막기 · (물방 소량 보정) |
| **민첩** | 스피드(턴주기) · 물리회피 · 마법 비껴맞음 |
| **솜씨** | 명중 · 크리(소량) |
| **행운** | 크리확률 · 리롤 · 크리랜덤배율 · 비껴무효 |

- **계단식(soft cap 없음)**: "10당 X" 보정은 `floor(스탯/10)` — 10 단위 채워야 발동, 9 이하는 0. 소프트캡 없이 100까지 선형(몰빵 효율 유지)

## 3. 파생 공식 (전부 확정)
```
■ 물리공격 = 힘 × (1 + floor(힘/10)×0.1)        // 힘100=200, 힘55=83, 힘10=11
■ 마법공격 = 지능 × (1 + floor(지능/10)×0.1)
■ 물리방어 = floor(힘/10)×3% + floor(체력/10)×1%  // 힘100체력45=34%, 힘55체력100=25%
■ 마법방어 = 30% + floor(지능/10)×3% (상한70%)     // 기본30%, 지능100=60%
■ 최대HP  = 50 + 체력×1.1 + 힘×0.5 + 지능×0.2 + 민첩×0.2 + 행운×0.3
■ 명중률  = 20% + floor(솜씨/10)×5% (상한80%)      // 솜씨100=70%, 솜씨55=45%
■ 물리회피 = 10% + floor(민첩/10)×2.5% (상한50%)    // 민첩100=35%
■ 마법회피(비껴맞음) = floor(민첩/10)×3% (기본없음)  // 민첩100=30%
■ 비껴맞음 효과 = 데미지 30% 감소 (물리는 랜덤30% 발동 / 마법은 민첩 확률)
■ 크리율  = 10% + floor(솜씨/10)×1% + floor(행운/10)×3.5% (상한70%)
■ 크리배율(랜덤) = 물리 2.5 + rand(0 ~ floor(행운/10)×0.15×2)  // 행운100=2.5~5.5배
              마법 1.5 + rand(0 ~ 위×0.6)
■ 행운리롤 = floor(행운/10)×4% (상한50%) — 롤마다 1회, 발동 후 다음 판정 스킵(쿨다운 토글)
■ 비껴무효 = floor(행운/10)×3% — 공격자 행운으로 비껴맞음 무시(풀뎀). 공격자 전용
■ 근성    = HP 50%↓부터, 받는뎀 감쇠 = floor(체력/10)×4% × 빈사도
              빈사도 = (0.5 - 현재HP%) / 0.5   // HP50%=0, HP0%=최대
■ 턴주기(초) = 10 - floor(민첩/10)×0.7 (최소 2초)  // 민첩100=3초, 민첩0=10초
```

### 방어기제 (패시브 확률 발동)
```
■ 무기막기: 힘 50+ 발동, 확률 30% + (힘-50)/10×2%,  데미지 50% 경감 (물리만)
■ 방패막기: 체력 70+ 발동, 확률 30% + (체력-70)/10×3%, 데미지 70% 경감 + 체력/3 고정감소 (물리+마법)
■ 마나실드: 지능 70+ 발동(패시브 상시),
    경감 = 10% + (지능-70)/10×2%  (지능100=16%)
    + 실드HP = 최대HP×30% (별개 방벽, 본HP 대신 먼저 깎임)
    + 실드 깨지면 1턴간 받는뎀 2배(취약)
```

### 전투 판정 흐름
```
[물리] 명중(솜씨,행운리롤) → 완전회피(민첩) → 방패막기>무기막기(실패시 행운 방어리롤로 랜덤막기)
       → 마나경감 → 비껴맞음(랜덤30%, 공격자행운으로 무효화) → 물리방어 → 크리(랜덤배율) → 근성
[마법] 확정명중 → 완전회피(행운리롤만) → 방패막기 → 마나경감 → 비껴맞음(민첩)
       → 마법방어 → 크리 → 근성
```

### 방어 행동 (버튼)
```
- 그 턴 공격 안 함 (코스트)
- 방어기제 무조건 랜덤 발동: 풀 = [빗맞음] + (힘50+ 무기막기) + (체력70+ 방패막기)
  ※ 마나실드(패시브)·회피는 방어행동 풀에서 제외
- 회복 = 10% + floor(체력/10)×1% (상한30%)  // 기사25%, 마법사14%
```

### 혼합 타격 (세이지 전용 기본공격)
> 세이지는 평타가 **물리 절반 + 마법 절반**으로 쪼개져 각각 해당 방어를 따로 통과 → **단일 방어로 완전히 못 막는** 하이브리드 딜러.
```
피해 = 물공×0.85 (→물방·무기막기) + 마공×0.85 (→마방)  [방패막기·마나경감은 둘 다]
- 명중: 마법식 자동명중(리롤 완전회피만). ※물리 명중판정에 묶으면 솜씨 낮아 헛쳐서 붕괴 → 자동명중이 정답
- 크리: 한 번 판정, 두 절반에 각각 물크/마크 배율 적용
- 타이틀/시그니처 자동 반영: 괴력의=물리절반↑, 현자=마법절반↑, 파괴(힘100)=물리관통, 심연의=마법관통
```
- 상성: vs광전사·기사(단일 방어)엔 강함, vs마법사(실드+마방+메테오)엔 약함

### 융합 타격 + 적응형 CC (마검사 전용)
> 마검사는 세이지의 **정반대** 하이브리드.
```
융합 타격 = (물공 + 마공) 한 방  →  방어자는 max(물방, 마방) 하나로만 경감 (자동명중, 물리회피는 가능)
- 마나실드(경감%+실드HP)는 융합에도 완전 적용 → 마법사에 약함
- 세이지(양쪽 약점 노림, 공격자 유리) ↔ 마검사(합쳐 때리되 방어자가 최고방어로 막음, raw는 큼)
```
**약점봉인**(1차, 적응형 CC): 상대 **최고 스탯**에 맞는 CC를 꽂음 — 힘=스턴(1턴)/민첩=슬로우(턴+1,2턴)/지능=침묵(스킬·캐스팅불가,2턴)/행운=행운굴림금지(2턴)/솜씨=명중-30%(2턴)/체력=자가회복+방어행동금지(2턴). **모든 스탯 <70(하이브리드)이면 폴백: 슬로우+방어행동금지 3턴**. 쿨3.
- 힘-스턴만 1턴(2턴은 힘딜러 락다운이 과함 → 광전사 24%). 나머지 CC는 2턴.

### 시그니처 패시브 (1차 스탯 100 도달)
> **캐릭 고유가 아니라 "스탯 100 도달 시 발동하는 스탯 고유효과"**. 커스텀 캐릭이 해당 스탯을 100 찍으면 누구든 동일하게 얻음. 프리셋 6종은 각자 한 스탯이 100이라 자동으로 하나씩 보유(전사만 100 없음 → 없음 = 상대적 균형추).

| 스탯 100 | 이름 | 효과 | 보유(프리셋) |
|---|---|---|---|
| **힘 100** | 파괴 | 물리공격이 상대 물리방어 **30% 관통** | 광전사 |
| **지능 100** | 심안 | 마법 크리 시 마나실드 소량 재생(최대HP 6%, 실드상한 내) | 마법사 |
| **체력 100** | 불굴 | HP 0 도달 시 **1회 최대HP 20% 부활** + 받는 CC 지속 **-1턴** | 기사 |
| **민첩 100** | 잔상 | 완전회피 직후 다음 자기 공격 **확정 크리** | 도적 |
| **솜씨 100** | 정밀 | 명중 상한 80→**90%** | 명사수 |
| **행운 100** | 천운 | 모든 피격 **30% 완전회피**(원작 "럭키 완전회피" 계승) | 행운아 |

- **밸런스 효과**: 언더독(기사·행운아)에 생존형 강효과가 몰려 자동 수렴. 전사(100 없음)는 상대적으로 진정 → 별도 너프 없이 스탯 구조만으로 편차 압축.
- **주의**: 관통·완전회피는 상대 상성에 따라 체감차 큼(관통은 상대가 물방탱일 때만, 완전회피는 전방위). 광전사 관통은 vs물방탱만 유효 → 광전사 하위(44%)는 "유리대포의 정당한 대가"로 수용.

## 3.5 AI 판단 로직 (태그 기반)
> **하드코딩 캐릭별 분기 폐기** → 스킬마다 태그 + 점수, 매 턴 점수 최댓값 선택. 순서 우선순위 버그 원천 차단. 이 로직이 곧 실제 봇 PvE AI가 됨(PvP는 유저가 버튼 선택).

**태그 (2종 + 기본)**
- **(태그없음) = 딜스킬**: 쿨 되면 평타보다 이득 → 점수 = 기대딜. 여러 개면 큰 것부터. (방패가격·약점간파·인스턴트캐스팅·피의갈망·동전던지기)
- **`제어`**: 가치가 딜이 아니라 "상대 턴 뺏기". 점수 = 기대딜 + 상대1턴딜×N. 상대 이미 CC면 사용불가. (암습·돌진)
- **`조건부`**: 쿨 됐어도 **지금 쓰면 안 되는 게이트** 있음:
  - 처형 = 상대 HP<25%일 때만 (충족 시 최우선)
  - 메테오(시전) = 내가 시전시간 버틸 만할 때만
  - 버프(광폭화·행운폭발) = 전투 안 끝날 때만(상대 HP 여유), 이미 발동 중이면 불가
  - 디버프(방어파괴·도발·견제사격) = 상대 살 날 많을 때만(상대 HP 여유)

**흡혈은 태그 불필요**: 피의갈망은 "평타 + 덤 회복"이라 HP 꽉 차도 손해 없음 → 그냥 쿨마다 쓰면 됨(딜스킬로 충분). 세부(버프/디버프/시전/흡혈)는 `조건부` 안 게이트로만 관리.

**선택 순서(점수 비교)**
```
1. 평타 기대딜을 기준선으로
2. 사용가능(쿨+게이트 통과) 스킬마다 점수 산정
```

## 7. 설계 원칙 (시행착오로 얻은 것)
- **순수 방어캐는 딜 없이 못 이긴다** (기사 8번 검증) → 딜은 스킬로. 방패가격 넣자 기사 36→67%
- **행운은 곱셈 보조, 공격은 덧셈 밑천** → 행운캐도 최소 딜 필요. 확률 버프만으론 안 되고 크리배율(딜) 얹어야 삼
- **민첩(턴)이 강력** → 턴주기 하한(2초) 필수. 1초턴이면 도적 89% 붕괴
- **상시 경감은 방어율과 곱연산으로 과함** → 마나실드는 "실드HP + 깨짐 리스크"로
- **CC(기절)는 최강 효과** → 3턴 기절=도적 69% 사기, 2턴으로. 수동방어 허용해 완전 즉사 방지
- **버프형 스킬은 쿨을 "버프 끝난 후" 시작** → 안 그러면 상시 유지(광폭화)
- **시전형은 시전시간이 딜 손실** → 리턴이 확실히 커야(메테오 ×4). AI가 "버틸 만할 때만" 판단
- **스킬은 공통 데미지 파이프라인으로** → 약점간파가 직접계산하다 물방·마나실드 누락(버그). 실제 구현 시 모든 딜을 attack() 통과시켜야
- **AI는 하드코딩 분기 대신 태그+점수** → 캐릭별 if 순서가 우선순위가 되면 버그(기사 도발이 방패가격 밀어냄). 스킬 태그(딜/제어/조건부)로 점수화해 최댓값 선택하면 구조적으로 해결
- **밸런스 지렛대와 플레이버를 구분** → 시그니처 패시브 관통%는 상성 탓에 광전사 승률을 못 움직임(플레이버). 언더독은 전방위 생존효과(부활·완전회피)라야 실제로 오름
