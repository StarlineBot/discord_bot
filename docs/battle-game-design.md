# 디스코드 턴제 전투 게임 — 설계 문서 (현재 상태)

> **이 문서는 현재 상태 기준으로 재작성됨(시간순 아님).** 앞에서부터 읽으면 지금 게임 그대로예요.
> 엔진·밸런스·UI 전부 `modules/battle.js` 하나에 있음. 밸런스 시뮬: `node docs/battle-sim/game-balance-sim.js [반복수]`.

## 0. 개요

`/듀얼` 명령 — 프리셋 캐릭 11종 중 하나로 랜덤 매칭된 상대(AI)와 1:1 턴제 전투. 게이지(턴값) 방식: 각자 `턴`값마다 행동, 빠를수록 자주 행동. 플레이어는 매 턴 공격/방어/스킬을 버튼으로 선택.

---

## 1. 1차 스탯 (6종, 각 0~100)

| 스탯 | 역할 |
|---|---|
| **힘** | 물리공격력, 물리방어 일부, 무기막기 |
| **지능** | 마법공격력, 마방, (마법무기)턴속도 |
| **체력** | 최대 HP, 물방 일부, 방패막기, 근성 |
| **민첩** | 턴속도(물리무기), 회피 |
| **솜씨** | 명중, 크리 확률 |
| **행운** | 크리 확률, 리롤(회피/명중 재굴림), 비껴무효 |

- 프리셋은 대부분 한 스탯이 **100**(시그니처 발동)이고 총합 ~300~315.
- 커스텀은 예산 ~320·상한 85(시그 차단) 규칙(9절).

## 2. 2차 스탯 계산 공식 (`derive`)

`step(s, per) = floor(s/10) × per` (10 단위 계단).

| 2차 | 공식 |
|---|---|
| **물공** | `round(힘 × (1+step(힘,10)/100))` × 시그·무기 보정 |
| **마공** | `round(지능 × (1+step(지능,10)/100))` |
| **최대HP** | `round(500 + 체력×1.7 + 힘×0.5 + 지능×0.3 + 민첩×0.3 + 행운×0.5)` |
| **물방** | `min((step(힘,3)+step(체력,1))/100 + 무기물방보너스 + 마도갑주, 0.80)` |
| **마방** | `min(min(30+step(지능,3),70)/100 + 무기마방보너스, 0.85)` |
| **명중** | `min(35 + step(솜씨,5), 80)/100` (솜씨100은 상한 90) |
| **회피(물회)** | `min(10+step(민첩,2.5),50)/100 + 무기회피보너스` |
| **크리** | `min(10 + step(솜씨,1) + step(행운,3.5) + 무기크리보너스, 70)/100` |
| **턴(속도)** | `max((10 - step(tempoVal,0.7)) × 무기tempoMul, 2)` — 작을수록 빠름 |
| **방패막기** | `검방(방어=방패) & 체력≥50 → (30 + floor((체력-50)/10)×3)/100`, else 0 |
| **무기막기** | `힘≥50 → (30 + floor((힘-50)/10)×2)/100`, else 0 (무기무관) |
| **근성** | `step(체력,4)/100` (HP 낮을수록 받는뎀↓) |

**tempoVal(턴 파생 스탯)**: 기본=민첩 / 스태프·완드·마도검=`지능` / 검오브·마도서=`max(힘,지능)`.
**크리배율**: 글로벌 base 물크1.5·마크1.2. 무기 `크리배율`이 **덮어씀**(활2.5·단검/마도서/검오브1.9). 크리 무기 없으면 1.5.
**물공 보정**: 체력100+한손무기 ×1.3(기사) / 솜씨100+활 ×1.05(명사수).

## 3. 시그니처 (1차 스탯 100 도달 시 발동 — 스탯 고유효과)

| 스탯100 | 이름 | 효과 | 보유 |
|---|---|---|---|
| 힘 | 파괴 | 물리공격이 상대 물방 **30% 관통** | 광전사 |
| 지능 | 심안 | 마법 크리 시 마나실드 소량 재생 | 마법사 |
| 체력 | 불멸 | HP 0 시 **1회 20% 부활** + 받는 CC 지속 **-1턴** | 기사 |
| 민첩 | 잔상 | 완전회피 직후 다음 공격 **확정 크리** | 도적 |
| 솜씨 | 정밀사격 | 공격 시 **15% 확률로 상대 회피 무효**(sigAim) | 명사수 |
| 행운 | 천운 | 모든 피격 **30% 완전회피** | 한탕주의자 |

전사·원드·세이지·마검·스펠은 100 스탯 없음 → 시그 없음(균형추).

## 7. 스킬 (캐릭당 액티브 + [패시브], 쿨=턴)

- 스킬 슬롯 최대 5개(2줄 UI). 쿨 무제한 재사용, `버프`=지속형(재사용 방지), `시전`=캐스팅.

**전사** — 방어파괴(쿨3: 딜+상대2턴 받는뎀+15%+상대HP6% 고정딜) · 돌진(쿨5: 물방무시딜+2턴 스턴, 자가HP-10%) · 차단(쿨4: **확정명중**, 시전취소+침묵 / 아니면 1턴 스턴+딜)
**광전사** — 재생의광기(쿨5: 즉시7% 회복+3턴 재생+공격, **기절 중에도 사용가능**) · 피의각성(버프: HP-10%→3턴 공격력×1.35 + **명중보정(상대 회피↓)**) · **[불굴]** 죽을 피해 시 1회 8% 회복 생존(직후 취약)+큰 피격 완충
**기사** — 방패가격(쿨3: 방어기반딜+상대HP10% 고정딜) · 방패들기(버프: 3턴 방패막기 경감 대폭↑) · **[가시방패]** 받는 피해 12% 반사(상시)
**마법사** — 화염구(시전: 마공기반, 인캐 즉발) · 메테오(긴 시전, **인캐 불가**, 초대형) · 인스턴트캐스팅(버프: 3턴 다음 시전 즉발, 메테오 제외) · 서리구(짧은 시전: 약딜+상대3턴 둔화, 인캐 즉발, **AI는 빠른 적한테만**) · **[마나환류]** 마법딜 30% 확률 40% 실드복구
**원드마법사** — 연쇄주문(버프: 4턴 볼트 2발·**서로 다른 종류**) · 마력충전(쿨5: 마나실드 재충전) · 볼트임팩트(시전: 볼트 압축 한방 마공×2.8)
**도적** — 암습(쿨10: 상대 3턴 기절+딜) · 처형(쿨5: 상대HP25%↓면 물공×5) · 백스텝(버프: 2턴 회피 대폭↑+딜) · 입막음(쿨4: **시전취소+2턴 침묵+딜**, 캐스터 카운터) · **[연속타격]** 공격 시 20% 확률 추가타(크리 안 터짐)

## 8. 핵심 시스템/메커니즘

**게이지 턴제**: `advance()`가 게이지를 굴려 플레이어 턴까지 진행. `turn`값마다 행동. 타임아웃(t≥600)=무승부.

**시전(cast)**: `s.cast`(남은턴)+`castDmg`+`castName`. upkeep이 카운트다운 후 발사. 화염구/메테오/서리구/볼트임팩트 공용. 일반 마법 판정(마방·천운회피·빗맞힘). **방해**: 피격 5% 중단 / 기절·차단·입막음·시전파괴 즉시 취소(취소돼도 `castCarry`로 다음 -1턴). **인캐**: 3턴 버프, 다음 시전 즉발(메테오 제외) — 심리전.

**스턴 중 방어 봉쇄**: 기절 중엔 능동 방어(회피·천운·방패막기·무기막기·패링) 전부 무효. **빗맞힘·마나실드·반사·근성은 유지**(수동).

**명중/빗나감 vs 빗맞음(별개)**: ①명중(솜씨 기반) 실패=빗나감(0딜) ②physSwing=딜변동(솜씨 기반 70~100%) ③비껴(30% ×0.70, 행운=비껴무효로 경감). ③만 🌫️로 로그 노출.

**마나실드**: 지능70+ 캐스터가 실드 풀(최대HP 22%) 보유, 피해 흡수. 지능 기반 `마나경감`(상시 받는뎀↓)도 있음. 마력충전/마나환류로 재충전.

**원거리 캐스터 체계**: 스태프·완드·활은 진짜 원거리 → 원거리페널티(근접 접근 시 턴 지연). 마도서·검오브·마도검은 근접(후려치며 마법).

**AI**: 태그 기반. 상대 시전 중이면 **차단기 우선**(차단·돌진·암습·약점봉인·시전파괴·입막음). 방어적 AI는 일반 스킬 스킵. 유틸 스킬은 score에 가치 반영 필요(안 그러면 AI가 딜 스킬만 씀).

- **인캐 힌트**: 인캐 중 버튼에 화염구="⚡ · 즉시" / 메테오="· 즉발불가".
